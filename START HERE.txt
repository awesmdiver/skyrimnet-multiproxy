SkyrimNet MultiProxy
====================

This tool connects SkyrimNet's AI NPCs to the AI provider of your choice -- a Claude or
ChatGPT subscription, an API key, or free local models through Ollama -- and starts the
proxy automatically whenever you launch Skyrim.

Before you start
-----------------
- Make sure SKSE64 is installed and working.
- Have at least one AI provider ready (or set one up after running the steps below).

Setup (one time only)
----------------------
1. Double-click setup.bat.
   It checks for Python (and installs it via winget if missing), installs the required
   Python packages, and displays the exact folder paths you need for step 3.

2. Install SkyrimNetMultiProxy.zip with your mod manager (Vortex or Mod Organizer 2) and
   enable it, just like any other mod. SkyrimNetMultiProxy.dll and SkyrimNetMultiProxy.ini
   will be placed into your game's Data\SKSE\Plugins\ folder automatically.

3. Open SkyrimNetMultiProxy.ini (either in Data\SKSE\Plugins\ or through your mod manager)
   and set the paths that setup.bat printed:
     PythonExe   -> Full path to your python.exe
     ProxyScript -> Full path to proxy.py (inside this folder)
     WorkDir     -> Full path to this unzipped SkyrimNet MultiProxy folder
     Port        -> 8000 (default; change only if another app uses port 8000)

4. Launch Skyrim through SKSE as usual. The proxy starts quietly in the background.

5. Open http://127.0.0.1:8000 in your browser, select your AI provider, and configure it:
     Claude  -> Claude CLI installed and logged in
     ChatGPT -> Codex CLI installed and logged in ("codex login")
     Ollama  -> Ollama running locally (or enter your Ollama Cloud key)
     Others  -> Paste your API key and click Save

6. In your SkyrimNet in-game settings:
     Endpoint: http://localhost:8000/v1/chat/completions
     API Key:  [Leave completely empty]
     Model:    Paste any model name from the dashboard (use the Copy buttons)

Upgrading from Claude SkyrimNet Proxy Launcher (ProxyLauncher)?
-----------------------------------------------------------------
- Remove the old ProxyLauncher mod from Vortex/MO2, then install SkyrimNetMultiProxy.zip.
- The new plugin will copy your old ProxyLauncher.ini settings to SkyrimNetMultiProxy.ini
  on first launch, but those paths still point to your old folder. Update ProxyScript
  and WorkDir to point to your new folder.
- Copy config.json from your old proxy folder into this one to keep your saved API keys,
  or re-enter them on the dashboard.

Want auto-close or custom logging?
-----------------------------------
Optional. Copy proxy.ini.example to proxy.ini in this folder and adjust the settings to
your liking. If you skip this, default settings will be used.

Something not working?
-----------------------
Read the full setup guide, FAQ, and troubleshooting steps on the project page:
https://github.com/awesmdiver/skyrimnet-multiproxy

If you plan to use Claude models through a personal subscription, please read the Terms
of Service notice in the README first -- it contains important account safety details.
